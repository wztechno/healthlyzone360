# Lane 6: the P2 sweep

Date: 3 November 2026. Built overnight on `P0-Stage1`. Tests are written and not run, per the brief.

## Built

1. **Rate limit.** The shipped default is 600 a minute, matching `deploy.sh`.
2. **Twilio.** An escalation text retries through its job: `tries = 4`, backoff 30, 90, 180 seconds. `#[\SensitiveParameter]` is on the number and the body.
3. **No recipients.** A warning in the logs, at most hourly per organisation and alert type.
4. **Timings.** A failed background refetch no longer unmounts the form, and the page's unsaved marker covers the timings.
5. **Storefront pause.** A banner on `/kitchens/[id]` gives the time orders resume.
6. **Off today on the recipes list.** Off today and Back on today are in the row menu.
7. **Suspect records.** `kitchen:suspect-records [--org=] [--same-arabic]`, read-only. It deleted nothing and did not run against any hosted environment.
8. **Top rated.** Hidden from the meals sort, the kitchens sort and the home titles while nothing is rated. The API returns `rating: null` for every kitchen today. The "under 30 min" chip hides the same way.
9. **Profile.** The developer sentence, Member since and the time zone are gone.
10. **Team and Roles.** A bad link gets a warning with a way back, as Customers has.
11. **Raw values.** Dates are formatted on `/apply/*` and the batch sheet. Record ids are gone from the batch sheet.
12. **Delivery zones.** The list now shows real area counts, and the detail page says "Every branch".
13. **Resale products.** Lists now ask for channels, so "On no channel" stops appearing on published items. Meals get the same, which also corrects `onSale` in the price list editor.
14. **Cost report.** With no range asked for, an empty month moves to the latest month with figures.
15. **Corporate wind-down.** Hidden: a typed address goes to `/corporate`.
16. **Sign out everywhere else** on `/devices`.
17. **Plan matrix.** A warning counts the combinations nobody can buy.
18. **`/kitchens/healthzone360-kitchen`.** Cause found by reading the code: the slug failed the id check, the query never ran, and the page stayed on Loading. Screens now pass it through, and an unknown slug gets the server's 404.
19. **Customer record.** Allergies and the latest ten orders.
20. **Copy the English.** An Arabic name identical to the English one now counts as untranslated, on the screen and at publication.
21. **Signed-out return link.** The customer layout hands the gate the address it arrived on.
22. **Re-deliver windows.** Open to `order.supervise_organisation` as well as the desk permission.
23. **Plain-language pass.** About 25 strings across recipes, meals, products, price lists and plans. "Derived", "server" and "management API" are gone from them.

## Decisions

- Only the staff escalation text retries. `SendCustomerOrderNotice` stays at `tries = 1`, as Lane 1 ruled: a retry would resend the email too, and a lost notice beats a doubled one. Its text goes through `send()`, which still reports and never throws.
- A retry can double a text if a timeout hides a message that did go. A manager can live with that.
- 429 and 5xx retry, and so does a dropped connection. Other refusals are reported once, because they would only be refused again.
- The limit's env override stays. Nothing else about limiting changed.
- Sign out everywhere else uses the existing `DELETE` per session rather than a new endpoint. Step-up is handled by the page's existing flow. It leaves the current session signed in.
- Off today shows both actions on every row with a published seller. The row has no calendar state to pick one, and both are idempotent.
- `paused_until` is on the single kitchen read only, not the list, and read without creating a settings row: a `GET` writes nothing. The banner shows a time, not a date. Pause is capped at 12 hours.
- Zones get `area_count` and `inactive_area_count` on the list in one grouped query. The list still leaves the areas out, as its docblock argues.
- A null `branch_id` means the organisation-wide map, so "No branch serves it yet" was wrong. The copy changed. The key stayed.
- Wind-down is hidden rather than fixed, because every read of it is on platform routes. The screen and its tests stay for a buyer-side read.
- Time zone is removed from Profile rather than defaulted to Beirut, since nobody can edit it there.
- Allergies on the record use the audited desk endpoint and its existing `OrderFulfilment` purpose, under the permission the record already requires. No new purpose was added. Orders show only with `order.view_organisation`.
- `customer_account_id` is a new filter on `/catalogue/orders`. It returns 400 on anything but a uuid, like the other filters.
- Copied Arabic stays a button, because a kitchen may paste and then edit. A brand with a truly identical Arabic name will now be refused at publication. Items already published stay published.
- The return link fix is the customer area only. Other gated areas may lose theirs the same way, since `useCurrentHref` reads the same bare pathname. It is unproven there, so I did not widen it.
- The test words live in one regex shared by PHP and Postgres. "Amela Harrington" is named in it, because no word list finds a plausible name. People are read per kitchen, so a tester with no membership does not show.

## Skipped

- **Batches.** Stuck in production, required Use by, and "Nothing to print" on labels. These are in Lane 4's area, which was still active when this lane finished.
- **A walk-in's allergy note reaching the driver.** Needs the owner's decision.
- **Fixing identical Arabic names.** Each needs a person's translation. `--same-arabic` lists them.
- **Removing test data.** The owner reviews the list first.
- **Filters other than Top rated and under 30 min.** Diet chips already follow real data. Open today, Collection and Offers plans filter on real fields.
- **Product list `noPacks`.** The list mapper also leaves pack variants empty. It looks like the same class of bug as channels, but was not in the audit and needs its own check.
- **Plain language beyond the strings above.** A scan found the worst words, not every awkward sentence.
