# Change Request Register

Changes to the agreed baseline (the revised platform foundation plan, 2026-07-30). A change request is required for: scope changes to the foundation, supersession of an ADR, launch-market or language changes, and any relaxation of the security/offline restrictions.

## Template

| Field | Content |
|---|---|
| CR ID | CR-NNN |
| Date raised | YYYY-MM-DD |
| Raised by | |
| Description | What changes and why |
| Baseline affected | Plan section / ADR / register entries |
| Impact | Scope, schedule, risk, security |
| Decision | Approved / Rejected / Deferred, by whom, date |
| Follow-up | Documents updated, ADRs superseded |
